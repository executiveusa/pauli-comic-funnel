## KEY FILES

### intelligent_model_router.py
Selects best model for task:
- Task analysis → Feature extraction
- Claude Haiku: Simple tasks, cost-sensitive
- Claude Sonnet: Balanced (default)
- Claude Opus: Complex reasoning
- Special handling for code, analysis, creative

### index.ts


## HOW AGENTS WORK

1. User triggers action (voice, UI, API)
2. PAULI-PRIME receives task
3. Routes to appropriate specialized agent(s)
4. Agent executes via CrewAI framework
5. Results aggregate back to PAULI-PRIME
6. Response returned to user

## TASK ROUTING LOGIC
- Financial query → CREDIT agent
- Code task → VEGA agent
- Strategy → NEXUS agent
- Creative → ARIA agent
- Analysis → ECHO agent

## ADDING NEW AGENT
1. Create folder: agents/[agent-name]/
2. Define in agents/[agent-name]/index.ts
3. Register in agents/index.ts
4. Add type to types.ts
5. Update this LLM.txt
